Drill

Semaine 47

sep 29, 2010

Catégorie : TRANSITION DEFENSIVE (Td-007)

Déroulement

- Trois files de joueurs à une baseline. Les ballons sont dans la file du milieu.

- Les premiers joueurs de chaque file effectuent un criss cross. Le premier joueur qui reçoit le ballon à hauteur des deux cônes (ici : le joueur 3) transmet ce ballon au Coach. C’est le signal d’une transition défensive pour les trois joueurs de cette première traversée (de l’endroit où chaque joueur se trouvait au moment de la passe de 3 au Coach). A un certain moment, le Coach fait rouler le ballon sur le sol; les trois joueurs se précipitent sur ce ballon, s’en emparent et quittent le terrain le plus rapidement possible pour retourner dans les files, tandis que les suivants démarrent.

- 1 va en 2. 2 va dans la file 3 et 3 va en 1 avec le ballon.

 

Coaching points

- Le Coach fait rouler le ballon sur le sol, ce qui oblige les joueurs à le ramasser (situation d’interception de ballon).

- Extension : Même procédé, mais quand le Coach lance le ballon, les joueurs le récupèrent le plus vite possible et terminent une contre-attaque. Dans ce cas, on peut exiger que les trois joueurs touchent le ballon avant d’inscrire le panier.
