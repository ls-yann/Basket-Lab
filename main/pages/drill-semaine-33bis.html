Catégorie : CONDITIONNEMENT PHYSIQUE (Cph-005)

Déroulement

- Les joueurs sont sur quatre files, deux à hauteur de chaque ligne des trois points. Le premier joueur des files 1 et 3 possède un ballon.

- Le premier joueur de la file 1 effectue la longue passe au premier joueur de la file 4, pendant que le premier joueur de la file 3 fait la passe au premier joueur de la file 2. Ensuite, le premier joueur de la file 4 passera le ballon au deuxième de la file 1 et le premier de la file 2 fera la passe au deuxième de la file 3.

- Les joueurs 1 et 2 sont toujours dans les deux mêmes files. Idem pour les 3 et 4. Après sa passe, chaque joueur contourne quatre cônes avant de prendre place dans la file voisine. Donc, par exemple dans le schéma, après sa passe, le joueur 1 sprinte autour des cônes a, b, c et d avant de prendre place dans la file 2.

 

Coaching points

- Dès qu’un joueur a fait une passe, il doit effectuer tout le trajet qui lui est imposé en sprint. Il récupère seulement à partir du moment où il a pris place dans la file suivante.
