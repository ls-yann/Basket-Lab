Drill

Semaine 59

déc 21, 2010

Catégorie : CONDITIONNEMENT PHYSIQUE (Cph-008)

Déroulement

- Deux files de joueurs. Une file 1 sans ballon à une baseline sous l’anneau; une file 2 avec ballons à la ligne des lancers-francs opposée.

- Le premier joueur de la file 1 effectue le parcours indiqué, à savoir : sprint jusqu’à la ligne médiane (a), glissements défensifs latéraux jusque derrière le cône 1 (b), nouveau sprint jusqu’au cône 2 (a); nouveaux glissements défensifs latéraux jusqu’au cône 3 (b); un dernier sprint pour recevoir le ballon (a). Passe du premier joueur de la file 2 et lay-up du premier de la file 1.

- Après son lay-up, 1 effectue le rebond et va derrière la file 2. Après sa passe, le premier joueur de la file 2 contourne les cônes 4 et 5 et va dans la file 1.

 

Coaching points

- Insister sur l’exécution correcte de tous les trajets imposés.

- Chaque joueur de la file 1 entame son parcours lorsque le précédent effectue son dernier sprint pour appeler le ballon pour un lay-up.
