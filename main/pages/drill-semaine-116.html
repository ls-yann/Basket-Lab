Catégorie : VITESSE DE REACTION (Vr-012)

Déroulement

- Deux files de joueurs de part et d’autre des lignes latérales. Les trois défenseurs partiront de trois emplacements différents, d’abord deux pas devant les attaquants (X1), ensuite à hauteur des attaquants (X2), puis deux pas derrière les attaquants (X3).

- Dès que le Coach passe le ballon à un attaquant (un des quatre ronds), le quatre contre trois vers l’autre panneau débute : vitesse de réaction de tous les acteurs !

- Après le quatre contre trois, les attaquants vont dans la file d’attente des défenseurs et les X vont dans la file des attaquants.

 

Coaching points

- Il s’agit d’un exercice de vitesse de réaction (et aussi de transition défensive). Il importe de réagir dès que le ballon quitte les mains du Coach.

- Si l’on dispose de moins de joueurs, on peut réaliser ce drill avec chaque fois 3 attaquants et deux défenseurs.
