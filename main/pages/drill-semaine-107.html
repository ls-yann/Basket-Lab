avr 16, 2012

Catégorie : VITESSE DE REACTION (Vr-011)

Déroulement

- Les joueurs sont sur une file à une extrémité de la ligne centrale. Trois ballons sont situés dans les zones A, B et C.

- Chaque joueur part de derrière les cônes a et b. Dès le départ d’un joueur, le Coach donne l’ordre dans lequel ce joueur doit toucher les cônes disposés à l’autre extrémité de la ligne médiane (ici : 3-5-2-4-1); puis le Coach désigne le ballon qui doit être ramassé le plus vite possible pour un lay-up (ici : B). Le joueur suivant démarre quand le précédent s’empare d’un ballon.

- Après le lay-up, le joueur redépose le ballon où il l’avait pris et rejoint la file d’attente.

 

Coaching points

- Si on dispose d’un assistant-coach, on répartit les tâches (exemple : le Coach donne l’ordre des cônes, l’assistant désigne le ballon qui doit être ramassé).

- On peut varier les shoots. Exemple : avec le ballon A, un dribble vers la ligne des lancers-francs et jump shoot; avec le B, lay-up; avec le C, jump shoot direct.

- Si on dispose de beaucoup de joueurs, on peut placer plusieurs ballons dans chaque zone.
