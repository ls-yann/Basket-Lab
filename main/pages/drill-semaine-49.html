Drill

Semaine 49

oct 11, 2010

Catégorie : CONDITIONNEMENT PHYSIQUE (Cph-007)

Déroulement

- Quatre files de joueurs. Les ballons sont dans la file 1 à hauteur d’une ligne des trois points. La file 4 est à hauteur de la même ligne des trois points. Du côté opposé, on a la file 2 aux trois points et la file 3 à la ligne des lancers-francs.

- Le premier joueur de la file 1 passe le ballon au premier de la file 2, qui prolonge vers le premier joueur de la file 3. Le premier joueur de la file 1 contourne les cônes a et b et reçoit le ballon de 3 pour un lay-up. Le premier joueur de la file 2 réalise le rebond et passe aussitôt à 1 parvenu à hauteur du cône c. Ce joueur passe au premier joueur de la file 4 qui prolonge vers la file 1 pour le premier joueur qui n’a pas de ballon. Celui-ci passe à 1 qui a contourné les cônes d et e avant de réaliser un deuxième lay-up.

- Après son deuxième lay-up, 1 passe derrière le cône f et va dans la file 2. Après son rebond, 2 va dans la file 3. Après sa passe pour le lay-up, 3 va en 4. Après sa passe à un joueur de la file 1, 4 fait le deuxième rebond, passe au même joueur de la file 1 et va dans cette file.

 

Coaching points

- C’est un drill de conditionnement physique : le rythme doit être très élevé !

- L’effort du joueur 1 doit être total, à partir de sa première passe à 2 jusqu’à son arrivée dans cette file ! Il doit donc passer, contourner les cônes a et b, réaliser un premier lay-up, contourner les cônes c, d et e, réaliser un deuxième lay-up, sprinter derrière le cône f et prendre place dans la file 2 !
