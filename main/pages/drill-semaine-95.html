Drill

Semaine 95

déc 5, 2011

Catégorie : TROIS CONTRE TROIS (3c3-010)

Déroulement

- Trois files de joueurs : une face à l’anneau, avec ballons, et deux files à l’aile.

- Le premier joueur de la file 1 passe au premier joueur de la file 2 (après démarquage) et réalise le screen away au profit du premier joueur de la file 3. Celui-ci remonte pour recevoir la passe du premier joueur de la file 2 dans le demi-cercle des lancers-francs. Le premier joueur de la file 3 feinte le shoot et remet inside au premier joueur de la file 2 qui profite à son tour d’un écran du premier joueur de la file 1.

 

- Après son deuxième écran, 1 va dans la file 2. Après son shoot, 2 va en 3. 3 effectue le rebond et va en dribble dans la file 1.

 

Coaching points

- Le drill peut commencer avec une passe du côté gauche et l’écran vers la droite.

- Le joueur de la file 3 doit d’abord attirer son défenseur imaginaire avant de profiter de l’écran de 1.

- On peut évidemment exécuter le drill avec des défenseurs; dans ce cas, les attaquants deviennent ensuite défenseurs et les défenseurs retournent dans les files d’attente.
