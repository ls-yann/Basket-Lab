Drill

Semaine 85

sep 19, 2011

Catégorie : UN CONTRE UN (1c1-010)

Déroulement

- Une file de défenseurs dans le coin du terrain à une baseline. Une file d’attaquants (avec ballons) en bordure de raquette à la même baseline.

- Les premiers joueurs des deux files partent en se passant le ballon. Ils réalisent cinq passes en tout, avec un lay-up du premier défenseur pour terminer. Le premier attaquant effectue le rebond tandis que le premier X joue en défense. Jusqu’au milieu du terrain, zig-zag defense. Ensuite, on joue le un contre un à fond.

- Après le un contre un, l’attaquant va dans la file des défenseurs, tandis que le défenseur réalise le rebond et va dans la file des futurs attaquants.

 

Coaching points

- Bien travailler sur un demi-terrain tant à l’aller pour les passes et le lay-up, qu’au retour pour le un contre un.

- Après un certain temps, les vagues de deux partent du côté droit et reviennent de l’autre côté.
